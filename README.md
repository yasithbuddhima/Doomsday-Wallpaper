# Avengers: Doomsday - Live Countdown Wallpaper

![](https://komarev.com/ghpvc/?username=yasithbuddhima-doomsday-wallpaper&color=4ade80&style=flat-square&label=DOOMSDAY+WAITLIST)

_"The universe requires correction... but first, we wait."_

Welcome to the **Doomsday Wallpaper**. This is a clean, cinematic, low-resource live desktop wallpaper designed specifically for **Lively Wallpaper**. It brings the official _Avengers: Doomsday_ live stream countdown directly to your desktop, ticking down the seconds until December 18, 2026.

## 🕰️ Features

- **True-to-Stream Design:** Replicates the exact layout of the official Marvel stream (Months : Days : Hours : Minutes : Seconds).
- **Low Resource:** Built with pure HTML/CSS/JS. No heavy video files draining your CPU while you're trying to study. (Seriously, I have an exam tomorrow and I'm making this instead of studying. Pray for me).
- **Dynamic Background:** High-quality background with a custom gradient overlay to match the glowing green cyber-aesthetic.
- **Accurate Calendar Math:** Correctly calculates real calendar months rather than just dividing days by 30.

## ⚙️ How to Install (Lively Wallpaper)

1. Ensure you have [Lively Wallpaper](https://rocksdanister.github.io/lively/) installed on your PC.
2. Download or clone this repository to a folder on your computer. Make sure the folder contains:
   - `index.html` (The actual wallpaper file)
   - `wallpaper.json` (The configuration file for Lively)
   - `README.md` (You are reading this now)
3. Open Lively Wallpaper.
4. Click the **"+" (Add Wallpaper)** button in the top right corner.
5. Click **"Browse"** and select the `index.html` file, or simply drag and drop the entire folder into the Lively window.
6. The wallpaper will process and apply to your desktop immediately.

## 🛠️ Customization

If you want to change the background image to a different Doctor Doom variant, simply open `index.html` in a text editor (like Notepad), find the `.background` CSS class around line 26, and replace the URL:

```css
background-image: url("YOUR_NEW_IMAGE_LINK_HERE");
```
